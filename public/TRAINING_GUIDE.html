English
  • Navigate to the "+ Add New Batch" tab in the portal menu.
  • Enter a unique Batch ID (e.g., B010).
  • Input Total Input (kg) (total raw banana blossom mass purchased, e.g., 510).
  • Input Yield Output (kg) (total finished flour produced, e.g., 25).
  • Link Farmer Sourcing: Select farmer's name, input the amount bought from them, and click + Append Supplier.
  • Click "Save Production Batch Ledger" to write securely to the Cloud.

❓ ចុះបើគ្មានអុីនធឺណិត ឬម៉ាស៊ីនមេមានបញ្ហា?

កុំបារម្ភ! ប្រព័ន្ធនេះមាន ប្រព័ន្ធរក្សាទុកបម្រុងស្វ័យប្រវត្ត (Local Offline Cache)។ រាល់បាច់ផលិតផលដែលលោកស្រីបញ្ចូល នឹងត្រូវបានរក្សាទុកក្នុងសតិកម្មវិធីរុករក (Browser)។ លោកស្រីនៅតែអាចបោះពុម្ពស្ទីគ័រ QR និងដំណើរការការងារបានជាធម្មតា ទោះបីជាគ្មានអុីនធឺណិតក៏ដោយ។ នៅពេលមានអុីនធឺណិតឡើងវិញ ទិន្នន័យនឹងត្រូវបានចម្លងទៅកាន់ពពក (Cloud Database) ដោយស្វ័យប្រវត្ត។

English

❓ What if the network drops or gets disconnected?

Don't worry! This portal is built with an Automatic Local Offline Cache. If internet connectivity drops, any batches or suppliers you add are saved locally in the browser's persistent state. You can still generate and print labels as usual. Once the connection is restored, everything synchronizes automatically with the cloud.
